Analiza dokumentów

PDF (PDF.js), TXT, DOC/DOCX (Mammoth), wklejony tekst → konfigurowalne pola → tabela wyników. Model jak w ChatGPT podłączany jest po stronie serwera (OpenAI API + klucz w .env). Otwórz stronę jako http://localhost:3001/ po npm start — bez wpisywania adresu API. Opcja regex działa bez sieci.

1. Źródło tekstu

Przeciągnij plik lub kliknij — obsługa: .pdf · .txt · .csv · .md · .docx
CSV i Markdown są wczytywane jako zwykły tekst (UTF-8).
